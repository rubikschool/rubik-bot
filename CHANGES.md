# Изменения: Переход на Webhook режим

## Что изменилось

### ✅ main.py
- ❌ Удалено: `run_polling()` - больше не опрашиваем Telegram API
- ❌ Удалено: Отдельный healthcheck сервер (не нужен)
- ✅ Добавлено: `run_webhook()` - обработка входящих HTTP запросов от Telegram
- ✅ Добавлено: Поддержка переменной `WEBHOOK_URL` из окружения
- ✅ Добавлено: Автоматическая настройка порта через `PORT` (для Cloud Run)

### 📋 Новые файлы

1. **DEPLOY_GUIDE.md** - подробная инструкция по деплою (пошагово)
2. **QUICK_DEPLOY.md** - краткая памятка для быстрого старта
3. **setup_webhook.sh** - скрипт для автоматической настройки webhook
4. **CHANGES.md** - этот файл (список изменений)

## Преимущества нового подхода

### 💰 Экономия
- Масштабирование до 0 инстансов (не платите за простой)
- Платите только за обработку сообщений
- Первые 2 млн запросов/месяц бесплатно

### ⚡ Производительность
- Мгновенная доставка сообщений (без задержки polling)
- Меньше нагрузка на Telegram API
- Автоматическое масштабирование при высокой нагрузке

### 🛠 Удобство
- Автоматический деплой из GitHub (continuous deployment)
- Простое обновление кода (просто git push)
- Встроенные логи и метрики в Cloud Console

## Что нужно сделать

### 1. Запушить изменения в GitHub
```bash
git add .
git commit -m "Switch to webhook mode for Cloud Run"
git push origin main
```

### 2. Задеплоить в Cloud Run
Следуйте инструкции в **QUICK_DEPLOY.md** (5 минут)

### 3. Настроить webhook
После деплоя:
- Скопируйте Service URL из Cloud Run
- Добавьте `WEBHOOK_URL` в переменные окружения
- Установите webhook через браузер или используйте `./setup_webhook.sh`

## Переменные окружения

| Переменная | Обязательна | Описание |
|------------|-------------|----------|
| `TELEGRAM_BOT_TOKEN` | ✅ Да | Токен от @BotFather |
| `GEMINI_API_KEY` | ✅ Да | API ключ от Google AI Studio |
| `WEBHOOK_URL` | ✅ Да | URL вашего Cloud Run сервиса (без /telegram) |
| `PORT` | ⚠️ Авто | Порт для webhook (Cloud Run установит автоматически) |

## Обратная совместимость

Если нужно вернуться к polling режиму:
1. Восстановите старую версию `main.py` из git
2. Удалите webhook: `https://api.telegram.org/bot<TOKEN>/deleteWebhook`
3. Запустите локально: `python main.py`

## Примерная стоимость

**Cloud Run (webhook):**
- Маленький бот (100-1000 сообщений/день): **$0-2/месяц**
- Средний бот (1000-10000 сообщений/день): **$2-10/месяц**

**vs polling режим:**
- Постоянно работающий инстанс: **~$20-50/месяц**

**Экономия: до 95%! 💰**

## Поддержка

Если возникли проблемы:
1. Проверьте логи в Cloud Run Console
2. Проверьте webhook info: `https://api.telegram.org/bot<TOKEN>/getWebhookInfo`
3. Убедитесь что все переменные окружения установлены правильно
4. Проверьте что бот упомянут в сообщении: `@bot_name промпт`
